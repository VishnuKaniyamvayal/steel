# Steel

> A Git-based, AI-native, local-first API client.

Steel is an API client built around a simple idea: your API projects should live as files, work seamlessly with Git, and stay on your machine. AI is integrated into the workflow to help you build and understand APIs—not as an add-on, but as a core capability.

> **Status:** Early development. APIs, features and project structure are subject to change.

---

Every feature in Steel is implemented with a strong focus on performance, minimal resource usage, and a lightweight architecture.

## Why Steel?

Most API clients revolve around cloud workspaces and proprietary formats.

Steel is built differently.

- 📂 **Git-native** — Collections are files that can be version-controlled with Git.
- 🤖 **AI-native** — AI is integrated throughout the development workflow.
- 💻 **Local-first** — Your data stays on your machine by default.
- ⚡ **Fast** — Built with Tauri and Rust for a lightweight desktop experience.
- 🎯 **Developer-focused** — Designed for people who spend their day building and testing APIs.

## Philosophy

Steel is built on a few principles:

- Your data belongs to you.
- Git should be the source of truth.
- AI should help developers—not replace them.
- Offline should be the default.
- Performance matters.
